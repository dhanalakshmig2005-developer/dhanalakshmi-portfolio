# Personal Portfolio Website

A responsive personal portfolio website built with **HTML5, CSS3 and JavaScript** as part of my Java Full Stack Development internship at **TVK Technologies**.

🔗 **Live Demo:** https://dhanalakshmig2005-developer.github.io/REPO-NAME/

## About

I am Dhanalakshmi G, a B.E. Computer Science and Engineering student at Arunai Engineering College (2023–2027). This website showcases my skills, projects, certifications and contact details.

## Features

- Dark theme with a clean, modern layout
- Sticky navigation bar with smooth scrolling
- Sections: Home, About, Skills, Projects, Contact
- Download CV button
- Contact form that opens the visitor's email app
- Fully responsive for mobile, tablet and desktop
